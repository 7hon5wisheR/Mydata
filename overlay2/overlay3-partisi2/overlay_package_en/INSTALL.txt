OVERLAY PACKAGE (new version)
==========================
Contents: setup_overlay.sh, setup_overlay_persist.sh, check_overlay_persist.sh,
      remove_overlay_persist.sh, update_broker.sh,
      overlay_persist/broker-persist, overlay_persist/sitecustomize.py

Installation (the overlay must be OFF: findmnt -no FSTYPE /  ->  ext4):
  unzip -o overlay_package.zip -d /home/alice/broker
  sudo bash /home/alice/broker/setup_overlay.sh

After that, the process runs automatically: reboot -> enable overlay -> reboot.
Check status: sudo bash /home/alice/broker/setup_overlay.sh --status
Check package: cd /home/alice/broker && sudo ./check_overlay_persist.sh

For Raspberry Pi devices that ALREADY have an older overlay version: disable the overlay first
(use the disable button at :8082), reboot, then run the two installation commands above.
