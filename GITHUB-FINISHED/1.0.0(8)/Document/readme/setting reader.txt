4. Install requirements.txt (for raspberry 3 or 4)



Check if venv is already installed. If not:

======================================
sudo apt update
sudo apt install -y python3-venv

======================================

Create and activate the virtual environment:

cd ~/broker
python3 -m venv venv
source ~/broker/venv/bin/activate


==================================
Edit `.bashrc`:

----------------
nano ~/.bashrc
------------------

Add the following lines at the bottom:

-----------------
cd ~/broker

if [ -f ~/broker/venv/bin/activate ]; then
    source ~/broker/venv/bin/activate
fi
--------------------

Save and exit:

* Ctrl + O, Enter
* Ctrl + X

Apply the changes:

------------------
source ~/.bashrc
-----------------

Now install the requirements:(file 4. Install requirements.txt)
